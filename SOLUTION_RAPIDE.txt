ÉTAPE 1: Ouvrir Console du Navigateur
──────────────────────────────────────
  • Appuyer sur F12
  • Aller dans l'onglet "Console"
  • Taper:
    localStorage.clear()
  • Appuyer sur Entrée


ÉTAPE 2: Fermer Complètement le Navigateur
───────────────────────────────────────────
  • Fermer TOUS les onglets
  • Fermer la fenêtre du navigateur
  • Attendre 3 secondes


ÉTAPE 3: Rouvrir et Se Reconnecter
───────────────────────────────────
  • Ouvrir: http://localhost:4200
  • Se connecter avec vos identifiants
  • Username: samarsahar (ou votre username)
  • Password: votre mot de passe


ÉTAPE 4: Vérifier le Token
──────────────────────────
  • Appuyer F12 (Console)
  • Taper:
    localStorage.getItem('access_token')
  • Devrait afficher un long texte (token)
  • Si affiche "null" → recommencer Étapes 1-3


ÉTAPE 5: Tester l'Abonnement
────────────────────────────
  • Aller sur: http://localhost:4200/subscribe
  • Subreddit: python
  • Niveau: top
  • Cliquer "S'abonner"
  • ✅ Devrait afficher: "Abonnement enregistré"
